# ZoMoZAAA — Premium Gaming Discovery

A production-focused gaming discovery frontend built with Next.js 14, React, Framer Motion and RAWG.

## Setup

1. Copy `.env.example` to `.env.local`.
2. Add your real RAWG key:
   `RAWG_API_KEY=...`
3. Install dependencies:
   `npm install`
4. Run:
   `npm run dev`

## Included

- Live RAWG game discovery and search
- Continuous hero carousel using real game records
- Real ratings, release dates, platforms, genres, developers and publishers
- Dedicated game detail pages
- RAWG screenshot endpoint + fullscreen screenshot gallery
- Responsive premium gaming UI
- Dark/light mode with persisted preference
- Toast feedback for user actions
- Skeleton loading states
- Server-side API proxy so the RAWG key stays server-side
- Pagination and filters
- Custom ZoMoZAAA logo and favicon
- Reduced-motion support

No fake game records or invented ratings are bundled into the application.
